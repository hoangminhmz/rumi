📋 Checklist - Đã làm chưa?

  • ☐ Disable tất cả .htaccess files (rename thành .htaccess.disabled)
  • ☐ Show hidden files trong cPanel Settings
  • ☐ Tạo file debug.php (PHP) trong cùng folder với file này
  • ☐ Check PHP version >= 8.1 trong cPanel

🎯 Đường dẫn nên là:

/public_html/rumi/path-debug.html ← File này

/public_html/rumi/test.php ← Từ GitHub

⚠️ Nếu trang này hiện nhưng click links bị 404:

  1. Disable .htaccess: Rename tất cả .htaccess thành .htaccess.disabled
  2. Check PHP files tồn tại: Xem trong File Manager có files .php không
  3. Test PHP version: Vào cPanel → Select PHP Version → Chọn 8.1+
  4. Clear browser cache: Ctrl+F5 để refresh

📸 Nếu vẫn không được - Chụp màn hình:

  1. Trang này (path-debug.html đang works)
  2. Kết quả khi click từng link ở trên
  3. File Manager showing files trong /public_html/rumi/
  4. cPanel Domains section (Document Root)
